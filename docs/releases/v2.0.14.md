# DSH Desktop v2.0.14

DSH Desktop v2.0.14 是 `v2.0.13` 的立即修正版：已有 Profile 私有 `mode`、`port`、`logLevel` 在启动时不仅驱动 Host 组合，也同步回 settings service，设置页面显示值与当前运行配置保持一致。

## 修复内容

- 首次使用 Profile 时，从共享旧 `settings.yaml` 导入三个 Desktop 字段并写入 Profile 私有状态。
- Profile 已有私有状态时，以私有状态为准启动，并在 Host boot 后同步 settings service；不会把另一个 Profile 的共享旧值显示为当前值。
- 同步只覆盖 `mode`、`port`、`logLevel`，不会复制窗口、更新、日志目录、安装 ID 或其他插件 namespace。
- 保留 `v2.0.13` 的 Windows installer quit handoff、精确进程路径范围、30 秒优雅退出预算和 ZIP/NSIS 恢复语义。

## 兼容与边界

- DeepSeek Harness 继续固定 `0.1.1-rc.2` package family，Better Sidebar 继续固定 `0.17.1`。
- 不接入 Harness alpha、Remote gateway、一次性 token、参考桌面私有服务或 7z 原地解压。
- Windows Setup 与主程序仍未配置 Authenticode 签名；SHA-256 只用于完整性核对。

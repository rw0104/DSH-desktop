# DSH Desktop v1.0.5

发布日期：2026-08-19

## 用户摘要

修复底部终端在 shell 退出后仍显示连接、但输入无效的问题，并恢复 Windows 侧边栏浏览器与终端能力。

## 变更

### 修复

- PTY 退出时现在会发送退出状态并关闭 UI terminal WebSocket。
- 客户端自动重连并重新生成 shell，不再把键盘输入静默丢弃。
- Better Sidebar 的 PowerShell 7、Windows PowerShell 和 `cmd.exe` 解析保持明确的 Windows fallback。

### 更新方式

- v1.0.5 使用 Windows x64 NSIS Setup/Update 安装包发布。
- 用户需要从 Release 下载新安装包并手动安装；当前流程不会静默替换已安装程序。
- 安装包未进行 Authenticode 签名，Windows 可能显示 SmartScreen 或 Unknown Publisher 提示。

## 验证

- UI terminal lifecycle 回归测试验证：shell 退出状态可见、WebSocket 使用 `1000 / terminal process exited` 关闭、退出后的输入不会继续写入死 PTY。
- Windows 发布 gate、runtime closure、Setup/Update installer verification 全部通过。
- 打包版 terminal smoke 验证 xterm 文本实际绘制，并通过真实 WebSocket/PTY 退出重连链路。

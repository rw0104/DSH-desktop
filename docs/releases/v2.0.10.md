# DSH Desktop v2.0.10

> Windows 安装包延续透明 unsigned 发布策略：安装器和主程序均验证为 `NotSigned`，GitHub Release 同时记录资产大小与 SHA-256。Windows 可能显示 SmartScreen 或 Unknown Publisher；SHA-256 完整性校验不等同于 Authenticode 发布者身份。

## 本轮升级

- 产品工作台从 `dsh-better-sidebar@0.15.1` 升级到 `0.16.1`，官方 DeepSeek Harness 继续固定在已验证的 `0.1.1-rc.2`，未修改上游子模块源码。
- 侧边栏支持把 Tab 拖入主会话区形成自由窗口，并保持 `registerTab`、`openTab`、`closeTab` 和插件 Tab 生命周期兼容。
- 新增默认关闭的 `sidebar_open` 模型工具，可在用户明确启用后打开文件、目录和 HTTP(S) 页面；关闭设置不会注入该工具。
- Markdown 预览支持经 DOMPurify 消毒的内嵌 HTML、目录大纲和本地相对图片；编辑器增加 Vue 与更多语言高亮。
- Git 面板支持多仓库与 linked worktree，`0.16.1` 对状态数量、仓库发现、超时和恢复入口设置上限，避免大工作区冻结与重启循环。
- 上游修复文件 API 工作区越界和符号链接检查，并修复 npm DSH `0.1.1-rc.x` 下内部 `ctx.betterSidebar` 读取导致的页面崩溃。

## 兼容性与依赖决策

- `0.15.1` 与 `0.16.1` 发布包的 `cordis.patch.yml` SHA-256 均为 `D363ACAD7F1521559194A3E04DE06FE68974B4A7B1AD3CC74DB54BCA63C4248B`；Loader 插入行未变化。
- `BetterSidebarService` 的 Desktop 消费面保持兼容，只新增 `floatWindows` feature。Desktop 继续通过 `ctx.get('betterSidebar')` 和最小结构接口注册 `desktop:changes` Tab。
- 上游移除了公开 `cordis` peer，改用 `@deepseek-ai/cordis` 类型基底；Desktop 自有的 `cordis@4.0.0-rc.8` 运行时接线不变。
- `@huanlin/dsh-plugin-better-locale` 是可选 peer，本产品未捆绑；中文和英文路径不依赖它。
- 该版本在 npm 发布未满 Yarn 默认 24 小时隔离期时完成审计，因此 `.yarnrc.yml` 只预批准精确描述符 `dsh-better-sidebar@0.16.1`，未放宽其他包。

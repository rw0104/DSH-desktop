## 升级前备份与回滚（已确认方案 1）

完全退出应用后，备份实际 DSH home、Electron user-data 和自定义工作区，记录应用
版本与自定义路径。每次后续升级都必须重新验证迁移、Profile/插件兼容和原件保留；
本次通过不保证未来任意版本互相读写。

保留官方 V0/V3 日志原件。**回滚只能将升级前完整备份恢复到独立目录，再让匹配的
旧版本指向该目录；禁止旧版直接复用升级目录。**不自动反向合并升级后新增消息。
旧 0.1.2 runtime 直接读取 V3 会拒绝，但在 V0/V3 混合目录可能读取旧 V0，显示过期
历史。因此“旧版能启动”不等于安全降级。升级后的新消息保留在升级目录，回滚副本
只含备份时点历史；再次升级前必须选定数据副本、备份并逐版验证，不能直接拼接分叉历史。

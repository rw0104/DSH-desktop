# DSH Desktop v2.0.12

DSH Desktop v2.0.12 将固定工作台 Better Sidebar 升级到正式发布的 `0.17.1`，官方 DeepSeek Harness runtime 继续固定在已验证的 `0.1.1-rc.2` package family。

## 主要更新

- 支持 `workspace` 和 `global` 范围的跨会话固定终端；home session 始终是权威状态，Agent terminal 暂时离线不会删除已固定 tab。
- Terminal URL 仅允许 Ctrl/Cmd+Click 打开 `http:` 或 `https:`；detached session 会先恢复持久化工作目录，再考虑 Host 进程目录 fallback。
- About 页显示 Host 权威更新状态：真实下载字节、独立校验阶段，以及完整性和 PE/DMG 校验通过后的等待安装状态。
- Renderer 只能通过同源 snapshot 和 generation-safe event stream 读取更新状态；下载和安装仍必须由用户明确确认。

## 兼容与安全边界

- Better Sidebar 精确固定 `0.17.1`；其发布版 `cordis.patch.yml` 以及 `registerTab/openTab/closeTab` 服务面继续兼容本产品 rc2 Profile。
- 旧 Sidebar state 无需迁移；非法 pin scope/cwd 只会剥离 pin，不会丢弃 tab。
- Desktop 成品仍能解析 `@deepseek-ai/dsh-client-runtime@0.1.1-rc.2`；不包含 Harness alpha package 或 Remote gateway contract。
- Windows 安装包未签名，Windows 可能显示 SmartScreen 或“Unknown Publisher”；安装前可核对下方 SHA-256。

# DSH Desktop v2.1.0

DSH Desktop v2.1.0 收敛了实时语音与安装器体验，并继续使用已审核的 DeepSeek Harness `0.1.1-rc.2` 和 Better Sidebar `0.17.1`。

## 主要更新

- 实时语音设置的普通用户入口只保留 Agent 级联（稳定）与 Qwen 原生语音 Agent（实验）两种模式；Qwen Agent 桥接仅作为开发诊断路径，已有内部值必须显式选择目标模式。
- Qwen/Host/Client 的原生音频事件使用 `voice.output.*`，与级联 TTS 的 `tts.*` 语义分离；会话面板显示真实音频来源、模型、权限主体和构建提交。
- Vision 模型能力继续从模型目录贯通到选择器和 Host admission，明确 text-only 模型仍在附件上传前拒绝。
- Windows NSIS 不再把 `THIRD_PARTY_NOTICES.md` 当作需要用户同意的 EULA；第三方声明仍随包提供。安装器默认 per-user，选择 all-users 时保留一次标准 UAC。
- 产品与 Desktop package 版本同步升级到 `2.1.0`。

## 验证状态

发布前必须完成：

- `corepack yarn install --immutable`
- `corepack yarn check`
- Windows x64 unsigned package、installer verifier 和安装后 smoke
- 真实 Qwen 账号的多轮、Function Call、审批、打断、重连和空闲恢复验收

Unsigned 测试包不作为正式 Release 资产；正式发布仍需独立完成 Authenticode 签名和远端资产校验。

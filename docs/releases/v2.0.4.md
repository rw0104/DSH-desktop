# DSH Desktop v2.0.4

发布日期：2026-08-20

## 必须升级

`v2.0.3` 已移除 `betterSidebar` 的必需 injection，但 Changes tab 仍通过 `ctx.betterSidebar` 直接访问未注入属性。rc8 Cordis 会将这种访问视为错误，因此部分用户仍会看到：`cannot get property "betterSidebar" without inject`。

`v2.0.4` 将可选 sidebar 读取改为 `ctx.get('betterSidebar')`，没有该 service 时正常启动。已经卡在 `v2.0.2` 或 `v2.0.3` 的用户需要手动安装一次 `v2.0.4`；安装后自动更新通道恢复，后续稳定版本不需要反复访问 GitHub。

## 修复内容

- `betterSidebar` 不再是必需 injection，也不再通过 Context 属性直接读取。
- 已移除的 Vision Toolkit/Better Sidebar 旧 profile bundle 仍会在启动迁移中被清理。
- 保留 v2.0.3 的 profile migration、自动更新、About、Workbench 和 rc8 兼容修复。

## 升级方法

1. 退出当前恢复窗口或闪退的 DSH Desktop。
2. 打开 [v2.0.4 Release](https://github.com/rw0104/DSH-desktop/releases/tag/v2.0.4)。
3. 运行 `DSH-Desktop-2.0.4-x64-Setup.exe` 覆盖安装。
4. 不要删除 `%APPDATA%\DSH Desktop` 或 DSH home；启动迁移会自动处理旧 profile。
5. 后续版本由应用后台检查 GitHub latest stable Release，确认后自动下载并安装 Setup。

# DSH Desktop v1.0.7

发布日期：2026-08-19

## 用户摘要

彻底移除 Files 首页无文件提示占用的左侧预览列，并修正 Windows 应用内更新的版本来源与下载地址。

## 变更

### 文件树布局

- 无文件且文件树已打开时，左侧预览列现在完全隐藏，文件树占满内容区宽度。
- 空状态下不再显示没有操作价值的分栏拖拽条。
- 选择文件后恢复正常预览/文件树分栏，原有持久化树宽度继续生效。

### Windows 应用内更新

- 更新检查改为读取本仓库 GitHub Latest Release 的 `tag_name`，不再使用错误返回 `2.0.1` 的旧公共版本接口。
- Windows 下载地址绑定检查到的确切版本，例如 `v1.0.7/DSH-Desktop-1.0.7-x64-Update.exe`，避免版本检查与安装包指向不同版本。
- Windows 用户无需手动访问 GitHub：应用检查、下载更新，用户确认后重启并启动安装器。
- macOS 仍由应用下载 DMG，用户随后手动替换应用。
- About 页的更新方式改为按平台显示上述真实行为。

### 工作区清理

- 移除先前打包 smoke 留在 `D:\Demo` 下的 `.tmp-v105-*` 和 `.tmp-v106-*` 目录，避免它们出现在文件树中。

## 验证

- Files 空状态布局回归：要求 `editorMain` 为 `display:none`、`editorTreeDock` 宽度为 `100%`、分隔拖拽条隐藏。
- 更新检查与下载测试：GitHub release tag 解析、稳定 SemVer、版本绑定的 Windows URL、PE/DMG 校验和 partial 清理。
- `yarn workspace dsh-plugin-desktop typecheck`: passed。
- Windows 发布 gate、runtime closure、Setup/Update installer verification 必须在发布前通过。
- 打包版 UI smoke 必须验证空状态文件树接近内容区全宽，以及 About 显示 `v1.0.7` 和正确的平台更新方式。

## 更新方式

`v1.0.6` 的旧版本接口配置错误，不能依赖它正确发现 `v1.0.7`。请手动安装一次 `v1.0.7`；从 `v1.0.7` 开始，后续 Windows 版本使用仓库 GitHub Release 完成应用内检查与下载。

Release: https://github.com/rw0104/DSH-desktop/releases/tag/v1.0.7

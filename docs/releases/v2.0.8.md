# DSH Desktop v2.0.8

## 修复内容

- 官方 DeepSeek Harness 子模块升级到 `dsh-v0.1.1-rc.2`，所有桌面/Market DSH package family 同步到 `0.1.1-rc.2`。
- Better Sidebar 升级到 npm `0.15.1`，保留 Desktop 自有 Host/Client 适配边界。
- 恢复 Windows “选择工作区目录”弹窗中的实际盘符选择器；当前机器检测到的 `C:`、`D:`、`E:` 会显示为 `C盘 (C:)`、`D盘 (D:)`、`E盘 (E:)`。
- 修复盘符选择异步清空导致的 `:\` 路径问题；选择 C 后提交路径为 `C:\`。
- 产物复制路径/内容和视觉模型能力误判按计划留到本安装包之后单独开发，不混入本版本发布变量。

## 已确认的后续问题

发布后确认 Windows 成品会过滤 Vision Toolkit 运行时清单要求的 `CHANGELOG.md`，导致该插件在每次启动时报告运行环境未就绪；这与用户配置的 API Key 无关。更新链、启动外链、视觉插件默认接管/不可禁用、模型能力元数据和产物复制的完整诊断见 [`2026-08-24_analysis-v2.0.8-update-startup-vision-report.md`](../2026-08-24_analysis-v2.0.8-update-startup-vision-report.md)，修复任务规划见 [`2026-08-24_v2.0.9-remediation-task-plan.md`](../2026-08-24_v2.0.9-remediation-task-plan.md)。

# DSH Desktop v2.0.2

发布日期：2026-08-20

## 升级前须知

- 本版本把产品基线从公开的 `v1.0.7` 提升到桌面上游 `2.0.1`，并将 DeepSeek Harness 从 `0.1.0-rc.7` 升级到 `0.1.0-rc.8`。
- DeepSeek Harness rc8 官方说明指出 SQLite 存储格式不兼容。升级前请备份 DSH home 与 Electron user-data；升级后不要假设 rc7 能读取 rc8 写入的数据。
- `v1.0.7` 仍需手动下载一次 `v2.0.2` Setup。安装 `v2.0.2` 后，Windows 版本会自动检查本仓库的后续稳定 Release，并在用户确认后下载和启动安装器；不会静默覆盖。

## 用户可见变化

- **DeepSeek Harness rc8**：支持 DeepSeek 原生图片请求、`/goal` 与 `/plan` 图文输入、`@` 文件/会话引用、可安装的 Claude Code/Codex 子代理、Windows 持久 PowerShell，以及图片载荷、取消流式回复、自定义 OpenAI 兼容网关、侧栏/工作流/模型选择和大历史分叉等修复与优化。
- **Community Market**：同步桌面上游的社区插件发现、安全 preview、受管安装/卸载、receipt、启用/禁用、失败回滚和恢复确认；市场兼容基线已升级为 rc8。
- **Workspace Workbench W0-W3.2**：提供 Session/Workspace 绑定、Activity Ledger、Changes 的 Unstaged/Staged/Last turn、hunk stage/unstage/revert、行级评论回送、统一终端生命周期、Git worktree 检查，以及 Host-owned managed worktree 创建/安全回收。
- **About 设置页恢复**：显示真实安装版本、`rw0104/DSH-desktop` 仓库、更新方式和当前版本 Release 说明，不再因桌面上游同步而回退。
- **产品自有更新通道**：后台与托盘检查改为 GitHub `rw0104/DSH-desktop` 最新稳定 Release；Windows 下载绑定精确 tag 和 `x64-Setup.exe`，不会误装 `anywhere-labs` 上游构建。
- **终端隔离**：未知 terminal 只有 `attached + cwd` 可以建立注册，跨 Session 的 output/input 事件不能隐式创建伪造终端。

## 如何升级

1. 打开 [v2.0.2 Release](https://github.com/rw0104/DSH-desktop/releases/tag/v2.0.2)。
2. 下载 `DSH-Desktop-2.0.2-x64-Setup.exe`。
3. 退出旧版 DSH Desktop，运行 Setup 完成覆盖安装。
4. 启动后在设置的 **关于** 页面确认版本为 `v2.0.2`。
5. 后续 Windows 稳定版本可等待后台提醒，或从托盘选择 **Check for Updates…**；确认后应用会下载 Setup，并再次询问是否重启安装。

安装不会主动删除 user-data、profile 或工作区。为防止 rc8 存储回滚不兼容，仍建议在首次启动前备份 `%APPDATA%\DSH Desktop` 与 DSH home。

## 已知限制

- 当前下游 Release workflow 只发布 Windows x64；macOS 会检查并报告新版本，但不会提供不存在的 DMG 下载。macOS 签名、公证和发布仍需独立闭环。
- Windows 安装包尚未进行 Authenticode 签名，可能出现 SmartScreen 或 Unknown Publisher 提示。
- W3.3 setup script/environment、W3.4 handoff/UI、Artifact Registry 与统一任务时间线不属于本版本，继续按 Workspace Workbench 计划推进。
- rc8 的 `dsh-client-ui-primitives` npm 包缺少声明的 source map；测试会显示 Vite source-map 警告，但 build、类型与行为测试通过。
- Yarn 仍会报告 rc8 官方 bundle 内部的 peer 声明警告；Desktop 与 Community Market 自身的 workspace peer provider 缺口已经补齐。

# DSH Desktop v2.2.0

v2.2.0 将桌面产品迁移到 DeepSeek Harness `0.1.2-rc.1` 与 Better Sidebar `0.18.0`，并修复此前升级候选在安装后无法加载插件的问题。版本号从 `2.1.0` 提升为 `2.2.0`，用于明确区分原版安装器、迁移测试包与本次构建。

本记录用于源码推送和本地验证；GitHub Release 及其下载资产单独发布。

## 相对 v2.1.0 的变化

| 项目 | v2.1.0 | v2.2.0 |
| --- | --- | --- |
| Harness | 0.1.1-rc.2 | 0.1.2-rc.1 |
| Better Sidebar | 0.17.1 | 0.18.0 |
| Cordis / Loader | 4.0.1 / 1.0.2 | 4.0.2 / 1.0.3 |
| Electron / React / pnpm | 43.4.0 / 18.3.1 / 11.7.0 | 不变 |

### 会话与工作台

随 [Harness RC1](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.2-rc.1) 引入过程内容折叠、会话宽度与字号调节、回答用量和耗时统计、完整历史导航、连接状态与重连，以及图片显示和压缩改进。子 Agent 的模型选择和后续消息能力同步升级。

随 [Better Sidebar 0.18.0](https://github.com/omdsh-dev/DSH-better-sidebar/releases/tag/v0.18.0) 引入统一“文件变动”页签，合并 Git 与本轮文件读写两种视图，增强 diff 预览、侧边对话和工作区路径围栏设置。

实时语音的 Qwen 级联、Qwen 原生实验模式与豆包入口在 v2.1.0 已经存在；本次主要完成运行时适配，不把既有语音能力重复列为新增。

### 安装与插件加载修复

- 打包保留 RC1 Host 需要的 Typert 描述文件，解决 controller 导入缺失。
- Electron 完成 Web token/cookie 认证交换，并保留 Desktop 启动参数。
- 修正模型选择器图片能力标签的下游 Yarn patch。原错误使整个组合脚本语法解析失败，界面误报首个等待加载的 typert-registry 未注册。
- afterPack 对全部物理 Web client 执行 classic-script 解析和精确注册检查；Profile smoke 获取生产路由真实 combo，验证每批注册完整性。
- 修正 CommonJS 从 Profile 回退到安装目录的解析，并让 Agent Preset 健康检查识别 ASAR 内插件，解决新会话误报 Standard Preset 的 23 个插件不可解析。检查同时覆盖真正缺失插件的拒绝，未跳过预设校验。

### 插件兼容性

Harness RC1 移除了旧 APIProxy，并拆分 Client runtime、session/workspace 和 store 接口。依赖这些旧接口的第三方插件须升级到支持 RC1 的版本。Better Sidebar 0.18.0 要求 Harness RC1+，不能单独配回旧的 0.1.1-rc.2 运行时。

Desktop/Market 已完成对应 API、Profile 结构、settings 和安装时 peer 校验适配。默认继续使用文件式会话持久化；使用旧可选 SQLite 后端的用户需按上游说明先用旧版导出。

## 验证与产物

客户端修复已在原 desktop Profile（含 IM 插件）通过安装启动健康检查，设置和 Profile manifest 保持一致。2.2.0 的完整检查、版本化安装器和独立启动验证结果将在本记录中补齐。

本地 Windows 安装器命名为 `DSH-Desktop-2.2.0-x64-Setup.exe`。未配置 Authenticode 签名的构建须标为未签名测试产物；版本号升级本身不代表完成真实账号语音、macOS 设备或所有第三方插件的验收。

# DSH Desktop 2.2.6 本地测试候选

2.2.6 修复图片模型经普通聊天接口调用失败的问题，并将图片协议、结果处理和异步任务执行拆分为可复用的适配机制。普通会话继续直接使用选中的供应商和模型。

- 阿里云已知 Qwen-Image 2.0 模型自动使用同一工作区的原生生成接口，支持临时图片链接保存和后续编辑引用。
- 修复自定义供应商无正文 400/413 被误判成上下文超限、进而触发压缩的问题。
- 供应商可以复用已有图片协议，新协议通过受信任 Host 插件注册；共用执行器负责结果转换、下载、持久化、取消及异步任务查询。
- 供应商级图片协议默认值只影响图片输出模型，文本模型保留原聊天接口。未知协议会给出明确错误，不自动尝试其他供应商。

接入方式与验收要求见[图片协议接入说明](../plugin-image-protocols.md)。本轮使用本地接口测试和实际包内界面验证；真实账号的模型权限、地区和生成结果需要另行实测。

Harness 保持官方 RC1 发布包及原有 submodule pin，Sidebar 保持 0.18.0，pi-ai 保持 0.84.4。官方开发分支及桌面参考仓库有更新，本轮未将未经兼容性审查的提交混入修复，下一步迁移范围记录在[同步记录](../upstream-sync.md)。这是本地测试候选，不代表已经发布 GitHub Release。

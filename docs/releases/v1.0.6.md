# DSH Desktop v1.0.6

发布日期：2026-08-19

## 用户摘要

收紧文件预览空状态，新增设置中的 About 页面，并继续保持底部终端在 shell 退出后的自动恢复。

## 变更

### 新功能

- 设置新增“关于”页面，显示当前版本、仓库地址和当前版本 Release 说明链接。
- About 页面明确说明当前更新方式：下载新的安装包并手动安装；当前更新流程不会静默替换已安装程序。
- Host 将实际桌面版本传递给 renderer，About 页面显示的版本与安装包一致。

### 体验调整

- 文件预览尚未选择文件时，说明改为紧凑的顶部空状态，不再在编辑区垂直居中占满大块空间，文件树成为主要视觉入口。

### 修复

- 底部 UI terminal 的 PTY 退出后主动关闭 WebSocket，触发现有重连逻辑生成新的 shell，避免出现“显示已连接但输入无效”。

## 更新方式

1. 打开 [v1.0.6 Release](https://github.com/rw0104/DSH-desktop/releases/tag/v1.0.6)。
2. 下载对应平台安装包。
3. 退出 DSH Desktop 后运行新安装包完成覆盖安装。
4. 重新启动应用，在设置的“关于”页确认版本号。

用户数据、profile 和会话目录由应用 user-data 管理，安装更新不会主动删除它们。安装包当前未进行 Authenticode 签名，Windows 可能显示 SmartScreen 或 Unknown Publisher 提示。

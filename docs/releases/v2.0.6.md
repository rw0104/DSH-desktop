# DSH Desktop v2.0.6

## 修复内容

- 左侧 Workspace 行和会话任务行的鼠标右键直接打开各自的官方 actions menu，不再渲染 Desktop 自己的一项式透明浮层。
- “在资源管理器中打开”直接调用 Desktop native directory route，启动系统文件管理器，不再把目录传给内部 Files 面板。
- Workspace 根目录请求按已绑定 checkout 做安全匹配；右侧 Explorer 目录请求继续使用 Session binding、symlink 和 containment 校验。
- 增加三仓库上游同步台账和更新准入规则：官方 Harness、Better Sidebar、桌面参考实现。

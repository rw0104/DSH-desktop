# DSH Desktop v2.0.13

> `v2.0.13` 已由 `v2.0.14` 取代。`v2.0.14` 修正已有 Profile 私有值未同步回设置服务的问题；请安装 Latest Release。

DSH Desktop v2.0.13 改进 Windows 运行中升级的退出协作，并按 Profile 隔离 Desktop 自己的启动偏好。官方 DeepSeek Harness 继续固定已验证的 `0.1.1-rc.2` package family，Better Sidebar 继续固定正式发布的 `0.17.1`。

## 主要更新

- Windows 安装器在覆盖运行中的 DSH Desktop 前，会通过产品专用 single-instance flag 请求有序退出；Cordis dispose、待写入状态和 active-run marker 有机会完成后才进入 30 秒等待。
- 安装器进程检查限定为当前 `$INSTDIR\DSH Desktop.exe` 的规范化绝对路径。安装目录里的 helper 或其他目录中的同名程序不会阻塞升级，也不会被 fallback 终止。
- 两个 Profile 的 `mode`、`port`、`logLevel` 写入 Desktop 私有的 `profile-preferences/<sha256(Profile directory)>/state.json`。窗口 bounds、更新状态、安装 ID、日志目录等设备级状态仍保持全局。
- 旧的共享 `settings.yaml` 仍会被校验并作为首次导入来源；已有 Profile 私有值在启动时覆盖共享旧值，设置修改以原子文件写入保存。

## 兼容与安全边界

- 本版本不接入 Harness `0.1.2-alpha.1`、Remote gateway、一次性 token、alpha Client contract 或参考桌面私有版本服务。
- 不修改 `deepseek-harness/` 子模块、`@deepseek-ai/dsh-*` `0.1.1-rc.2` family、Better Sidebar `0.17.1` 或根 README 的产品身份。
- 仍保留当前 electron-builder ZIP/NSIS 原子替换路径。参考仓库的 7z 原地解压方案需要额外故障注入和恢复证明，本版本不采用。
- Windows 安装包和主程序未配置 Authenticode 签名，Windows 可能显示 SmartScreen 或“Unknown Publisher”；SHA-256 只用于完整性核对。

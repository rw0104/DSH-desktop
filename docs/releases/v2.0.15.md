# DSH Desktop v2.0.15

DSH Desktop v2.0.15 修复社区插件市场在选择合作来源后长时间停留在加载状态的问题，并使 1024Store 与 dshfind 的当前公开目录负载重新满足原生客户端性能和完整性边界。

## 主要更新

- 市场侧边栏弹窗默认进入可快速返回的“发现”，不再冷启动时直接触发“可安装”完整索引。
- 1024Store 内置 Host client 支持有界 gzip；自定义来源仍保持 identity-only 和较小默认传输上限。
- dshfind adapter 从 124 次分页遍历改为一次官方原子 `/v1/catalog` 下载，校验 `data_version`、总数、时间戳、重复身份、精确 origin 与规范化上限后再发布索引。
- “可安装”首次同步显示明确的耗时说明和辅助技术 busy/live 状态；市场弹窗补齐 Tab/Shift+Tab 焦点陷阱、关闭后焦点恢复与嵌套确认对话框保护。
- 合作来源说明和 attribution 由 Client locale 提供，不再在英文界面混入固定中文 Host 文案或反向混入英文 notice。

## 兼容与安全边界

- DeepSeek Harness 继续固定 `0.1.1-rc.2` package family 与子模块 `b150a551…`；Git 上的 `0.1.2-alpha.1` 尚未成为 npm `latest`，不混入本次市场修复。
- Better Sidebar 继续固定正式发布的 `0.17.1`；桌面参考 `v2.0.4` 只作只读比较。
- 只有两个编译期固定合作来源允许 gzip：1024Store 解压后上限为 16 MiB，dshfind 为 32 MiB；用户添加的标准来源继续使用原有严格策略。
- 完整规范化索引上限为 25,000 条。达到上限、快照不完整、版本非法、来源跨 origin 或解压超限都会 fail closed，不发布部分列表。
- Windows 安装包和主程序仍未配置 Authenticode 签名；SHA-256 只用于完整性核对。

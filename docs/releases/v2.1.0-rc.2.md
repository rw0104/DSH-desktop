# DSH Desktop v2.1.0-rc.2

本候选版本完成官方 DeepSeek Harness `dsh-v0.1.2-rc.1` 的完整接入。Desktop Host、Web Client、Profile/Loader、Community Market、Voice/Agent 合同和 Windows 打包闭包均已迁移；Better Sidebar 使用正式 `0.18.0`（peer 明确支持 RC1），不混入 main/alpha 快照。

## 主要变更

- DSH package family 与 Cordis 基础设施统一到 Harness `0.1.2-rc.1` / Cordis `4.0.2`，补齐 RC1 新增的一方 peer 闭包。
- 用 Session Controller 分页替换旧 APIProxy history 读取；deliverable verifier 支持 RC1 event/chunk history，并保留路径授权和文本/二进制安全边界。
- 重新生成 RC1 app boot、directory picker、workspace、attachment/conversation、settings/model capability、deliverables、DeepSeek streaming、Win32 process 和 Sidebar 兼容补丁。
- 保留 Compatibility/Advanced Profile 行为、Community Market receipt/restart 边界、Vision `inputModalities` admission 和 Windows 隐藏控制台策略。

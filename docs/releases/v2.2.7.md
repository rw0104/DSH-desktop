# DSH Desktop 2.2.7 更新说明

2.2.7 增加高级模式的图片保存、工作区文件上传和会话内容菜单，并修复 Sidebar 本地图片预览、Sidechat 恢复和菜单定位。本页说明相对前次推送的 2.2.6 源码新增的行为，以及本轮选择性同步的修复。

**Windows x64 正式版**：[Release 页面](https://github.com/rw0104/DSH-desktop/releases/tag/v2.2.7) · [下载安装器](https://github.com/rw0104/DSH-desktop/releases/download/v2.2.7/DSH-Desktop-2.2.7-x64-Setup.exe)。安装器未进行 Authenticode 签名，Windows 可能显示 Unknown Publisher / SmartScreen 提示。

本次将已验证测试包按正式名称 `DSH-Desktop-2.2.7-x64-Setup.exe` 发布；二进制内容与哈希不变，`latest.yml` 同步采用正式名称。产品发布为 stable / Latest，上游 Harness 仍固定已验证的 RC1，不升级到 alpha。

从 2.0.16 稳定版升级还会获得此前 2.1.0 预发布版的 Qwen/豆包实时语音入口、凭据管理及 Agent 级联；Qwen 原生语音 Agent 继续标为实验模式。2.2.0—2.2.6 的源码改进一并包含：

- Harness 从 0.1.1-rc.2 迁移到 0.1.2-rc.1，Sidebar 从 0.17.1 迁移到 0.18.0；包含会话显示与历史导航改进、统一文件变动视图，以及安装后插件加载修复。见 [2.2.0](v2.2.0.md)。
- 修复 RC1 语音凭据读取、语音按钮灰显和模型图片能力传输；增加可覆盖的图片输入能力自动识别，区分显式能力与名称推断。见 [2.2.1](v2.2.1.md)。
- 改进语音动画、字幕独立滚动、任务期间的可恢复控制条、拖动避让和播放时序；普通工作区与审批仍可操作。见 [2.2.3](v2.2.3.md)及 [2.2.6](v2.2.6.md)。
- 接入原生图片生成及可复用供应商协议，修复阿里云图片模型调用、自定义供应商错误分类和重复生成重试；图片结果可持久保存并继续引用。见 [2.2.6](v2.2.6.md)。

## 新增交互与使用方式

### 在高级模式添加图片或工作区文件

点击输入框旁的 **+**，可以选择“添加图片…”、“上传文件到工作区…”或“指令 /”。图片多选、粘贴和拖放继续沿用 Harness 的附件处理；原有附件栏滚动、溢出箭头、失败重试、Commands 和已启用的语音入口均保留。

普通文件上传到当前会话绑定的工作区或 worktree，保存在 `.dsh-uploads/file-*/` 中；使用独立目录保存同名文件，不覆盖已有文件。界面每次最多选择 **10 个文件**，每个不超过 **25 MiB**。上传成功后把文件相对路径加入草稿；输入暂不可用时，可稍后点击“插入引用”。

例如上传 `需求说明.pdf` 后，草稿会引用工作区中的实际文件，Agent 可通过可用工具读取它。上传本身不自动解析 PDF/Office、不执行文件，也不把文档转换成图片附件；解析能力取决于当前工具。

### 保存原图与操作会话内容

- 在原有图片预览中使用“保存图片”，将已存储的原始附件字节保存到用户选择的位置。原有单图、多图与轨迹图片显示继续使用上游组件。
- 在会话消息、代码块或链接上右键，按所在内容显示复制选中文本、复制代码、复制整条消息、复制链接和打开链接等操作。
- 消息和代码块可通过键盘聚焦，并使用 `Shift+F10` 或菜单键打开内容菜单；指令菜单打开时恢复输入框焦点。

高级模式提供上述 **+ 菜单、图片预览保存工具栏和会话语义菜单**。兼容模式保留上游默认客户端；两种模式共用桌面原生文本菜单及 Host 提供的产品上下文。

### 让 Agent 获得准确的产品上下文

普通聊天、恢复会话、子会话和实时语音获得同一份 DSH Desktop 版本、系统、模式及实际功能说明。Agent 可以区分桌面应用、Harness Runtime、当前工作区与安装目录，知道上传文件以路径提供给工作区工具。

这不会改变当前模型身份，也不会自动读取屏幕、剪贴板或选区。已有图片生成和供应商协议能力继续保留，详见 [2.2.6 更新说明](v2.2.6.md)和[图片协议接入说明](../plugin-image-protocols.md)。

## 本轮选择性同步的修复

| 场景 | 修复后的行为 | 使用方式或影响 |
| --- | --- | --- |
| Sidebar Markdown 拆分预览 | 本地图片引用通过会话范围内的媒体路由显示，支持相对路径、中文和空格，保持会话图片身份隔离 | 在编辑器打开 Markdown 并切换预览，例如 `![示意图](./images/demo.png)` |
| Sidechat 子会话 | 正确标记继承历史；父会话尚未处理的输入不会被当作子会话自己的待处理输入 | 从已有会话创建 Sidechat，继续各自的对话 |
| Sidechat 刷新或冷恢复 | 恢复子会话的模型选择及请求参数，保留未显式指定推理强度时的适配器默认语义 | 重载或重新打开子会话后继续发送消息 |
| Sidebar 子菜单 | 按实际菜单尺寸与可见区域定位，改善视口边缘、窄窗口和长菜单的可用性；Escape 关闭后恢复焦点 | 在窗口四角或窄窗口打开菜单，用键盘导航与关闭 |
| Windows 后台进程 | CLI 插件安装和非交互子进程使用隐藏控制台选项，减少后台命令弹窗；交互终端保持原行为 | 正常安装插件或运行后台命令，无需额外设置 |

开发与维护侧同步补齐了 Windows 并行测试前的 Electron 准备，以及隔离临时目录的清理。清理逐项识别目录链接并只解除链接，不进入链接目标；普通检查将临时目录和 Harness home 放入同一个可清理的隔离目录。

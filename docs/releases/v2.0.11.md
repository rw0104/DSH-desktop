# DSH Desktop v2.0.11

## 发布摘要

本版本跟进桌面参考仓库 `v2.0.3` / `master` 中已经与当前 DSH Desktop 组合证明兼容的改进，同时保持官方 Harness `0.1.1-rc.2` 和 Better Sidebar `0.16.1` pin 不变。

## 主要变更

- Community Market 使用 storefront 图标，并为 Desktop 设置使用独立显示器图标；
- Market package-manager 失败保留有界 stdout/stderr 诊断，写入 Desktop 日志并展示在失败弹窗；
- 失败弹窗提供 Host 推导的精确安装命令和 DSH Terminal 入口，不自动重试已消费的确认；
- Workspace 文件夹拖拽优先于聊天附件遮罩，支持 Chromium 尚未暴露 File 的悬停目录；
- 新增三个官方 rc2 下游 patch：附件、会话 drop target、设置图标；
- 产品版本从 `2.0.10` 更新为 `2.0.11`。

## 依赖与安全边界

- 官方 Harness：`dsh-v0.1.1-rc.2` / `b150a551b8d465e31e418e1b2eaf5e79bbb7d28e`；
- Better Sidebar：`0.16.1` / `f9153dfc1ce47cf43445c1b351ee3ae47b4ad9f1`；
- 未接入 Sidebar `main` 的未发布 `0.17.0` pinned-terminal 功能；
- 未修改 `deepseek-harness/`，未覆盖根 README 的产品身份；
- package-manager 输出和异常原因均有长度上限，不把任意 Renderer 文本当作命令执行；
- Windows 安装器保持 `NotSigned`，SHA-256 只用于完整性核对，不代表 Authenticode 发布者身份。

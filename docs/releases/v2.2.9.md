# DSH Desktop 2.2.9

2.2.9 修复 Profile 运行时依赖投影导致的跨版本混用。Windows x64 正式 Release 仅在完整验收通过后发布；安装器未签名。本版内置 Harness 0.1.6-alpha.2 与 Better Sidebar 0.19.1，Desktop 的正式版本不改变上游 alpha 标记。

## 修复内容

- Desktop 不再向共享 `profiles/node_modules` 写入内核依赖投影，使用官方进程内 Profile resolution generation。
- 旧、新、断裂共享链接不决定内置 Host/Client 代码；同名 Host 与 Client metadata 使用相同的安装归属。
- 真实 Profile 插件仍可使用自身私有 ESM/CommonJS 依赖；受污染 Profile 不会被删除或改写。
- 开发 `yarn dev` / `yarn start` 默认使用一次性 DSH home、Electron user-data、临时目录和工作目录；退出后清理。启动前审计 Profile 是否指向当前 checkout。
- 保留官方 Plugin Manager、离线安装、四文件恢复日志、重启健康门禁、旧 Profile 和 Session 迁移能力。

## 升级和回退

升级前完全退出应用，并手动备份完整 DSH home、Electron user-data 和工作区。2.2.9 不会自动清理历史链接、迁移未知插件或删除会话。旧版本不包含本次解析修复；回退时请将升级前完整备份恢复到独立目录，再由匹配的旧版本使用升级前数据。

第三方插件需自行兼容 Harness 0.1.6-alpha.2；市场收录不保证所有旧插件兼容。没有自动合并升级后新增会话，也不通过删除数据隐藏错误。

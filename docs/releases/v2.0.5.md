# DSH Desktop v2.0.5

## 修复内容

- 恢复 `omdsh-dev/DSH-better-sidebar` 作为右侧完整工作台，固定 rc8 兼容的 `0.14.0`，不再使用上一版自写的简化 Workbench。
- 保留 Desktop 的 Changes/Review、Activity、Terminal projection 和 Worktree Host 能力，并将 Changes 重新注册到上游 `betterSidebar` service。
- 左侧 Workspace 目录和右侧 Explorer 目录支持右键“打开目录”，路径经过 Session checkout containment 校验后交给系统文件管理器。
- 修复窄窗口下自写固定面板造成的布局/modal 点击风险，恢复上游面板宽度、折叠和响应式行为。
- Community Market、包元数据、Issue 和帮助入口继续统一到 `rw0104/DSH-desktop`。

## 验证

- Root headless gate：Market 268/268；Desktop full suite 通过（平台跳过项按 CI 规则保留）。
- Packaged Electron：官方侧栏 panel host、Files Explorer、New Session、Workspace 右键菜单和 Changes tab 注册均通过。
- Windows x64 NSIS installer：unsigned 构建，`verify-win-installer` 通过。

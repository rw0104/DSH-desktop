# DSH Desktop v2.2.3

本次改进语音窗口、字幕跟随和任务交互，并修正模型发现错误。生图模型能否被列出与能否执行生图是不同能力；本次没有新增 Images/DashScope 图像生成执行器。

## 语音动画来源与移植范围

2.2.2 的球体是 Canvas2D 近似实现，并非用户提供的 pm01 动画的完整移植。本次使用 III.PICS `realtime-presence` 的 WebGL shader、motion profiles 和降级绘制核心，基线为 `5dcac08bdf9ab81c1c729ff50c5fadc8962eb45b`，保留五层 FBM、双向云流、分频响应、音频相位及起音扰动。shader 指纹回归避免其退化为另一套近似效果。

DSH 只适配自身状态名、桌面尺寸、DPR 上限 1.6、上下文恢复与资源清理；不搬入原项目的页面、鉴权、计费、Provider 或参考视频。来源与 MIT 声明随第三方说明提供。不宣称整页布局或像素尺寸与 pm01 完全一致。

输入以 16kHz、输出以 24kHz 分析；回复动画按实际排队播放时间更新，不按网络包到达时间提前变化。音频特征以稳定对象供 renderer 逐帧读取，字幕不随每个音频帧重排。正常 WebGL/2D 绘制不再同时叠加静态降级球。

## 窗口、字幕与任务

- 语音改为非模态工具窗口，保留 DSH 主工作区和原有审批界面。
- 标题、动画、控制按钮保持可见；连接信息默认折叠，只有字幕区独立滚动。
- 靠近末尾时自动跟随；手动阅读历史会暂停跟随，可点击“回到最新”。收起和恢复保留通话及阅读位置。
- 语音委托任务或工具启动时自动收起成小型控制条，显示任务状态，可静音、结束或恢复窗口；不会自动批准操作。
- Escape 和“返回工作区”只收起窗口，不结束通话；要停止语音，应使用明确的结束或关闭按钮。
- 保留原生语音的打断规则。收起不是结束；需要避免新发言打断任务时，可先静音。
- 界面跟随中英文和已有 DSH 主题。设计依据 Apple 的 Agency、Flexibility 和内容/控制分层原则作平台适配，不是全局 Apple 外观或 Liquid Glass 替换。

## 模型列表与生图

之前使用 `openai` 等预设时，“获取模型”可能直接返回内置聊天目录，即使用户已指定中转地址。现在显式地址优先；支持 OpenAI 模型列表协议的预设也查询其实际端点。根地址补齐 `/v1/models`，带路径前缀的地址保持前缀。服务端返回的非聊天模型 ID 不被过滤掉；不支持该列表协议的原生预设仍保留内置目录。

模型必须以供应商接口和账号实际返回的列表为准，不能保证某个兼容 `/models` 端点枚举全部原生任务模型。[GPT Image](https://developers.openai.com/api/docs/guides/image-generation) 和 [Qwen Image](https://help.aliyun.com/en/model-studio/qwen-image-api) 使用各自的生成接口；仅添加模型名不会让聊天适配器自动具备图片输出。现有“图片输入”表示看图，不等同于生图。
